## 📚 Contenido del curso

El curso cubre los fundamentos de .NET y C# desde cero, incluyendo:

- Configuración del entorno de desarrollo (Visual Studio / VS Code)
- Tipos de datos, variables y operadores
- Estructuras de control: condicionales y bucles
- Métodos y funciones
- Programación Orientada a Objetos (POO): clases, herencia, interfaces
- Colecciones: listas, pilas, colas
- Manejo de excepciones
- Acceso a datos con Entity Framework
- Introducción a APIs REST con ASP.NET
- Introducción a MVC con ASP.NET
